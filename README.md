# 首页信息流分类（B站 & YouTube）

给 B站 和 YouTube 的首页推荐加一个开关，把视频分成「专业 / 精选娱乐 / 娱乐」几类，想看哪类就切哪类。用大模型（默认 DeepSeek）判断每个视频属于哪一类。

两个脚本，各管一个网站：

- `bilibili-feed-mode.user.js` — B站首页
- `youtube-feed-mode.user.js` — YouTube 首页

## 四个模式

- **全部**：原始首页，什么都不改
- **娱乐**：所有娱乐内容
- **精选娱乐**：只留能让你心情变好的娱乐（治愈、搞笑、有才华、萌宠、美食这类），过滤掉引战、猎奇、贩卖焦虑的
- **专业**：只留能学到东西的内容（科普、技术、财经分析、纪录片这类），而且要求语气冷静，那种靠"要崩盘了""劲爆"博眼球的即使话题专业也不算

B站的专业模式下还有个「热榜内容」滑条：可以按比例掺一些知识区、科技区和全站热门的视频进来，用来看看自己推荐流之外的东西。

## 怎么装

**第一步，装一个用户脚本管理器**（一个浏览器扩展，用来运行这类脚本）：

- 电脑 Firefox / Chrome / Edge：装 [Violentmonkey](https://violentmonkey.github.io/)（免费开源）或 Tampermonkey，去对应浏览器的扩展商店搜名字点安装就行
- 装完浏览器右上角会多一个图标

**第二步，装脚本**，点下面的链接，管理器会弹出安装确认，点确认：

- B站版 → https://greasyfork.org/zh-CN/scripts/592929
- YouTube版 → https://greasyfork.org/zh-CN/scripts/592932

**第三步，填 Key（可选但推荐）**：打开 B站或 YouTube 首页，左下角会出现模式开关，点开关右边的 ⚙ 按钮，填入你自己的 DeepSeek API Key（去 [platform.deepseek.com](https://platform.deepseek.com) 注册申请，自己付费，很便宜，见下面成本）。两个网站要各填一次。

不填 Key 也能用——会改用脚本内置的关键词规则来分类，免费、不联网，但判断没那么准。

## 花多少钱

分类靠调用大模型，成本很低。实测（DeepSeek，每次一批 24 条视频）：

- 每个视频平均花 74 个 token
- 每分类 1000 个新视频，大概花 2 到 3 毛钱
- 看过的视频结果会存在本地，再刷到不花钱
- 就算每天重度刷上千条，一个月也就几块钱

用的是 DeepSeek 便宜的那档模型（`deepseek-chat`）就够了，不用旗舰模型。也可以换成别的 OpenAI 接口格式的服务。

## 关于隐私

- 开了 Key 之后，只有视频的**标题、作者名、标签**会发给 DeepSeek 用来分类
- 不会发你的账号、Cookie、观看记录这些
- 你的 API Key 只存在自己浏览器里，不写在代码里，也不传去任何服务器
- 分类结果存在本地，没有任何数据上报

## 不影响平台和创作者

- **不屏蔽广告**：B站的推广卡、课堂，YouTube 的信息流广告，所有模式下都照常显示
- **不改跳转**：点视频还是跳到平台原来的播放页，播放和收益都在平台那边正常发生
- 后台请求控制得很克制，和你平时正常刷的量差不多
