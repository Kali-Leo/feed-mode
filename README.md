# 首页信息流分类（B站 & YouTube）

给 B站 和 YouTube 的首页推荐加一个分类开关，把视频分成「专业 / 精选娱乐 / 娱乐」几档，点一下就能切换，只看自己当下想看的那一类。

分类由 AI 完成。B站版自带一个小型分类程序，**什么都不用填就能用**（免费、不联网）；如果你愿意接入更强的云端 AI（需要填一个密钥，见下文），分类会更准，费用也很低。YouTube 版的情况稍有不同，下面「要不要填密钥」一节会分别说明。

包含两个脚本，各对应一个网站：

- `bilibili-feed-mode.user.js` — B站首页
- `youtube-feed-mode.user.js` — YouTube 首页

## 几种模式

- **全部**：原始首页，不做任何改动
- **娱乐**：只看娱乐内容
- **精选娱乐**：只保留让人放松愉悦的娱乐（治愈、搞笑、才艺、萌宠、美食等），过滤掉引战、猎奇、贩卖焦虑的内容
- **专业**：只保留有信息量的内容（科普、技术、财经、纪录片等），并且要求语气平和；那些用"崩盘""劲爆"制造焦虑、博眼球的内容，就算话题专业也不算在内

## 安装

1. 先装一个用户脚本管理器扩展：[Violentmonkey](https://violentmonkey.github.io/)（免费开源）或 Tampermonkey。在浏览器扩展商店里搜名字就能装，Firefox、Chrome、Edge 都支持。
2. 再装脚本，点下面的链接、由管理器确认安装：
   - B站版 → https://greasyfork.org/zh-CN/scripts/592929
   - YouTube版 → https://greasyfork.org/zh-CN/scripts/592932
3. 打开对应网站首页，左下角会出现模式开关。

装好后即可使用。要不要填密钥，见下一节。

## 要不要填密钥？

这里说的密钥，是 [DeepSeek](https://platform.deepseek.com)（一家 AI 服务商）的 API Key——一串你自己去申请的字符，填进脚本后，脚本就能用它调用 DeepSeek 的云端 AI 来分类。申请是免费的，只有实际用到时才按用量扣费，而且很少（见下节）。

**B站版：可以不填。** 自带的分类程序免费、不联网，日常使用「专业」等模式足够了。填入密钥后，改由更强的云端 AI 把关，分类更准，「精选娱乐」这种更细的区分尤其明显。

**YouTube 版：建议填。** 它没有自带模型，不填密钥时只能用简单的关键词规则来分类，能用但不太准；填入密钥后才由云端 AI 分类，效果好很多。

填法：点开关旁边的 ⚙ 按钮，把密钥粘进去。两个网站要分别设置。

> 填了密钥后，B站版开关条上会多出一个滑条，用来在「更准」和「更省」之间调节：往省的方向拉，更多分类交给免费的自带程序，偶尔可能有个别分错；往准的方向拉，更多交给云端 AI 复核，花费略高。旁边会显示大概有多少比例用到了云端。

## 费用

只有在你填了密钥、用到云端 AI 时才会产生费用，而且很低：

- 一次实测中，连续刷全新内容，每一千条视频大约花 **2 分钱**。
- 已经分过类的视频再次刷到，不再重复收费。
- 正常日常使用，一个月通常也就几毛到几块钱。
- 开关条上会实时显示当天花了多少钱，鼠标悬停能看明细。你随时知道自己花了多少，也可以用上面说的滑条把花费压得更低。

## 隐私

- 只有在你填了密钥时，才会把视频的**标题、作者名、标签**发给 DeepSeek 用于分类；不发送你的账号、Cookie 或观看历史。
- 密钥只存在你自己的浏览器里，不写进代码、不上传到任何地方。
- 所有分类结果都存在本地，不会上报。
- B站版为了提前准备好要显示的内容，会调用 B站自己的推荐接口来预加载视频——这和你手动刷新首页是一回事，用的是你自己的登录状态，不涉及额外的数据外发。（YouTube 版不做这种预加载。）

## 对平台的影响

- **不屏蔽广告**：B站的推广卡、课堂，以及 YouTube 的信息流广告，在所有模式下都照常显示。
- **不改跳转**：视频链接都指向平台原本的播放页，播放量和创作者收益都正常算在平台内。
- 后台请求量和你正常浏览时相当。
