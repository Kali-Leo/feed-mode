# 首页信息流分类（B站 & YouTube）

为 B站 和 YouTube 首页推荐流提供分类开关，将视频分为「专业 / 精选娱乐 / 娱乐」，一键切换。

分类由脚本内置的本地模型完成，装上即可使用；填入 DeepSeek API Key 后改由云端模型复核，精度更高。

- `bilibili-feed-mode.user.js` — B站首页
- `youtube-feed-mode.user.js` — YouTube 首页

## 模式

- **全部**：原始首页
- **娱乐**：仅娱乐内容
- **精选娱乐**：保留正向情绪的娱乐（治愈、搞笑、才艺、萌宠、美食等），过滤引战、猎奇、贩卖焦虑的内容
- **专业**：保留有信息量的内容（科普、技术、财经、纪录片等），并要求语气克制；以「崩盘」「劲爆」式措辞博眼球的内容，即使话题专业也不计入

## 安装

1. 安装用户脚本管理器：[Violentmonkey](https://violentmonkey.github.io/) 或 Tampermonkey。
2. 安装脚本：
   - B站版 → https://greasyfork.org/zh-CN/scripts/592929
   - YouTube版 → https://greasyfork.org/zh-CN/scripts/592932
3. 打开对应网站首页，左下角出现模式开关。

## API Key（可选）

不填即可正常使用，本地模型离线分类。填入后分类交由云端复核，「精选娱乐」这类细分判断明显更准。

Key 在 [platform.deepseek.com](https://platform.deepseek.com) 申请，通过开关条上的 ⚙ 按钮填入，两个站点分别设置。填入后开关条会出现「容忍」滑条，在精度与调用量之间取舍，旁边显示预计送云端的比例。

本项目完全免费，无任何付费功能，不经手任何费用。

云端复核产生的 API 费用由你与 DeepSeek 直接结算，价格以官方为准；不填 Key 则不产生任何费用。脚本会尽量少调用：本地模型先行过滤，只将少数内容送云端，已分类内容缓存后不重复请求。开关条实时显示当日用量与折算金额，实际扣费以 DeepSeek 后台账单为准。

## 隐私

- 仅在填入 Key 后，向 DeepSeek 发送视频的标题、作者名、标签；不发送账号、Cookie、观看历史。
- Key 与全部分类数据只保存在本地浏览器，无任何上报。
- B站版会调用站内推荐接口预加载内容，等同于刷新首页，使用你自己的登录态，无额外数据外发。YouTube 版无预加载。

## 对平台的影响

- 不屏蔽广告：B站推广卡、课堂及 YouTube 信息流广告在所有模式下正常展示。
- 不改动跳转：视频链接指向原始播放页，播放量与创作者收益不受影响。
- 后台请求量与正常浏览相当。
