# 首页信息流分类（B站 & YouTube）

给 B站 和 YouTube 的首页推荐加一个分类开关，把视频分成「专业 / 精选娱乐 / 娱乐」几档，点一下就能切换，只看当下想看的那一类。

分类由 AI 完成。两个脚本都自带一个小型分类程序，**什么都不用填就能用**（免费、不联网）；如果你愿意接入更强的云端 AI（需要填一个密钥，见下文），分类会更准，费用也很低。

项目包含两个脚本，各对应一个网站：

- `bilibili-feed-mode.user.js` — B站首页
- `youtube-feed-mode.user.js` — YouTube 首页

## 几种模式

- **全部**：原始首页，不做任何改动
- **娱乐**：只看娱乐内容
- **精选娱乐**：只保留让人放松愉悦的娱乐（治愈、搞笑、才艺、萌宠、美食等），过滤掉引战、猎奇、贩卖焦虑的内容
- **专业**：只保留有信息量的内容（科普、技术、财经、纪录片等），并且要求语气平和；那些拿「崩盘」「劲爆」制造焦虑、博眼球的内容，就算话题专业也不算在内

## 安装

1. 先装一个用户脚本管理器扩展：[Violentmonkey](https://violentmonkey.github.io/)（免费开源）或 Tampermonkey。在浏览器扩展商店里搜名字就能装，Firefox、Chrome、Edge 都支持。
2. 再装脚本：点下面的链接，在管理器弹出的页面里确认安装。
   - B站版 → https://greasyfork.org/zh-CN/scripts/592929
   - YouTube版 → https://greasyfork.org/zh-CN/scripts/592932
3. 打开对应网站首页，左下角会出现模式开关。

装好后即可使用。要不要填密钥，见下一节。

## 要不要填密钥？

这里说的密钥，是 [DeepSeek](https://platform.deepseek.com)（一家 AI 服务商）的 API Key——一串你自己去申请的字符。把它填进脚本后，脚本就能调用 DeepSeek 的云端 AI 来分类。密钥归你所有，用量与费用也由你在 DeepSeek 后台自行管理（详见下面的「费用」一节）。

**B站版：可以不填。** 自带的分类程序免费、不联网，日常使用「专业」等模式足够了。填入密钥后，改由更强的云端 AI 把关，分类更准，「精选娱乐」这种更细的区分尤其明显。

**YouTube 版：可以不填。** v2.0 起同样自带分类程序，多语言标题都能处理；填入密钥后由云端 AI 复核，分类更准。

填法：点开关旁边的 ⚙ 按钮，把密钥粘进去。两个网站要分别设置。

> 填了密钥后，开关条上会多出一个滑条，用来在「更准」和「更省」之间调节：往省的方向拉，更多分类交给免费的自带程序，偶尔可能有个别分错；往准的方向拉，更多交给云端 AI 复核，花费略高。旁边会显示大概有多少比例用到了云端。

## 费用

**本项目完全免费，没有任何付费功能，也不向你收取任何费用。**

唯一可能产生的开销，是你自己填入密钥、使用 DeepSeek 云端 AI 时，DeepSeek 按你的用量向你收取的费用——这是你和 DeepSeek 之间的事，与本项目无关，具体价格以 DeepSeek 官方为准。不填密钥则完全不产生费用。

从实际用量看，脚本对 API 的调用很省：自带的本地程序会先处理掉大部分内容，只把少数送云端；已经分过类的视频再刷到时也不会重复调用。开关条上会实时显示当前的用量与按官方价折算的大致金额，鼠标悬停看明细，上面提到的滑条也能进一步压低调用量。**如果你在意开销，请自行关注你在 DeepSeek 后台的实际账单与用量。**

## 隐私

- 只有在你填了密钥时，才会把视频的**标题、作者名、标签**发给 DeepSeek 用于分类；不发送你的账号、Cookie 或观看历史。
- 密钥只存在你自己的浏览器里，不写进代码、不上传到任何地方。
- 所有分类结果都存在本地，不会上报。
- B站版为了提前备好要显示的内容，会调用 B站自己的推荐接口预加载视频——这和你手动刷新首页是一回事，用的是你自己的登录状态，不会额外外发数据。（YouTube 版不做这种预加载。）

## 对平台的影响

- **不屏蔽广告**：B站的推广卡、课堂，以及 YouTube 的信息流广告，在所有模式下都照常显示。
- **不改跳转**：视频链接都指向平台原本的播放页，播放量和创作者收益都正常算在平台内。
- 后台请求量和你正常浏览时相当。
