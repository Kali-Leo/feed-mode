# 首页信息流分类（B站 & YouTube）

为 B站 和 YouTube 首页推荐流增加分类开关，将视频分为「专业 / 精选娱乐 / 娱乐」，可在各模式间切换。

B站版 v2.0 起内置一个 64KB 的本地 AI 小模型（在 1.7 万条大模型标注语料上训练，详见 `research/`）：不填 API Key 也能离线使用「专业」模式主要功能；填入 DeepSeek Key 后，本地模型先免费过滤大部分内容，只把少数拿不准的送大模型复核——实测 token 消耗降至逐条全送的约 1/5，且最终判定仍由大模型把关、精度不降。

包含两个脚本，分别对应一个网站：

- `bilibili-feed-mode.user.js` — B站首页
- `youtube-feed-mode.user.js` — YouTube 首页

## 模式说明

- **全部**：原始首页，不作修改
- **娱乐**：全部娱乐内容
- **精选娱乐**：仅保留能带来正向情绪的娱乐内容（治愈、搞笑、才艺、萌宠、美食等），过滤引战、猎奇、贩卖焦虑类内容
- **专业**：仅保留有信息量的内容（科普、技术、财经分析、纪录片等），并要求语气冷静克制；以"崩盘""劲爆"等制造焦虑或博眼球的内容，即使话题专业也不计入

B站版开关条上另有「容忍」滑条（设置 Key 后显示）：调低则更多内容送大模型复核（更准更费），调高则更依赖本地小模型（更省，可能有少量错分或漏内容），旁边实时显示预计送大模型的比例。本地模型还会用大模型的判定结果在你的浏览器内做增量自适应（数据不出设备），越用越贴合你的内容领域。

## 安装

1. 安装用户脚本管理器扩展：[Violentmonkey](https://violentmonkey.github.io/)（免费开源）或 Tampermonkey。在浏览器的扩展商店搜索名称即可安装，Firefox、Chrome、Edge 均支持。
2. 安装脚本，点击链接后由管理器确认安装：
   - B站版 → https://greasyfork.org/zh-CN/scripts/592929
   - YouTube版 → https://greasyfork.org/zh-CN/scripts/592932
3. 打开对应网站首页，点击左下角模式开关旁的 ⚙ 按钮，填入 DeepSeek API Key（在 [platform.deepseek.com](https://platform.deepseek.com) 申请，费用自理，成本见下）。两个网站需分别设置。

不填 Key 亦可使用：B站版由内置本地小模型离线支撑「专业」模式（免费、无需联网），精选娱乐等细分改用关键词规则；YouTube 版无 Key 时使用关键词规则。

## 成本

以下为端到端实测数据（DeepSeek v4-flash，非峰时段价，实验记录见 `research/LOG.md` E9）：

- 本地模型先行过滤后，连续刷全新内容约每千条视频 2 分钱（约 1 分钱可分类 470+ 张卡）
- 已分类结果缓存本地、重复内容零费用；配合端上自适应，使用约一周后日常降至每千条 1 分钱以下
- 重度使用月成本约几毛钱；「容忍」滑条可进一步压低
- 开关条实时显示当日 token 用量与折算金额（精确累计自 API 返回的 usage，按峰谷时段计价），悬停看明细

默认使用 DeepSeek 低价档模型（`deepseek-v4-flash`，自动关闭思考模式）即可满足精度需求；也可替换为其他兼容 OpenAI 接口的服务。

## 隐私

- 启用 Key 后，仅视频的标题、作者名、标签会发送至 DeepSeek 用于分类
- 不发送账号、Cookie、观看历史等身份数据
- API Key 仅保存在本地浏览器，不写入代码，不上传至任何服务器
- 分类结果缓存于本地，无数据上报；本地小模型的自适应增量同样只存在你的浏览器里

## 平台影响

- **不屏蔽广告**：B站推广卡与课堂、YouTube 信息流广告在所有模式下均正常显示
- **不改动跳转**：视频链接指向平台原始播放页，播放与创作者收益均在平台内正常产生
- 后台请求受控，量级与正常浏览相当
