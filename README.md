# 首页信息流 娱乐/专业 模式切换（B站 & YouTube）

用 LLM 把首页推荐流按内容价值分类，一键在四种模式间切换。包含两个独立脚本：

- `bilibili-feed-mode.user.js` — B 站首页（功能最全：缓冲池预取、破茧混入、零位移信息流）
- `youtube-feed-mode.user.js` — YouTube 首页（纯 DOM 过滤，**零额外站内请求**，补货完全依赖 YouTube 自身的无限滚动 + 背压节流）

四种模式——

- **全部**：原生首页，不做任何改动
- **娱乐**：全部娱乐内容
- **精选娱乐**：只看能带来优质情绪价值的娱乐（治愈、欢笑、才华、匠心、萌宠、美好），过滤引战对立、猎奇审丑、贩卖焦虑的内容
- **专业**：只看有信息密度的内容（硬核科普、技术、财经分析、学术、深度纪录片）

另有「破茧」滑条（专业模式下）：按你设定的比例混入来自知识/科技分区和全站热门的圈外精选，作为打破信息茧房的手段。

## 特性

- **LLM 分类**：视频按「标题 + 创作者名（B站另含标签）」由大模型分四类（专业/精选娱乐/普通娱乐/营销水），营销号、卖课引流、标题党在过滤模式下自动隐藏
- **界面零侵入**：不在卡片上添加任何标记，页面观感与原生一致
- **缓冲池预取**（B站）：后台调用推荐接口提前分类，过滤模式下无饥饿感；池子持久化，刷新页面秒恢复
- **零位移信息流**（B站）：过滤模式下已显示的卡片永不前后移动
- **背压节流**（YouTube）：分类积压时自动暂停 YouTube 的无限加载，兼顾流畅与对平台服务器的克制
- **分类缓存**：同一视频只分类一次，成本极低（重度使用每月约几元人民币的 API 费用）
- **限流保护**：请求全局节流、随机间隔、指数退避、失败熔断，后台标签页自动降频

## 性能与成本（实测数据）

分类管线为低消耗设计，以下为真实批次实测（24 条/批，deepseek-chat）：

- **单条视频均摊 ≈ 74 token**（输入 57 + 输出 18，已含全部提示词开销）
- 系统提示词自动命中服务商上下文缓存：稳定运行时**未缓存输入仅 ≈ 4 token/条**
- 折算成本：**每 1000 条新视频约 ¥0.2~0.3**（DeepSeek 当前价格量级）；已分类视频走本地缓存，重复出现**零成本**——重度日刷千条，月成本也不过几元
- **不依赖旗舰模型**：默认使用轻量档 `deepseek-chat` 即达到项目所示精度，任何 OpenAI 兼容接口可替换
- **可完全脱离 LLM**：不填 Key 时退回内置本地关键词规则（免费、离线、零请求），精度较低但功能完整

## 安装

1. 安装用户脚本管理器：[Violentmonkey](https://violentmonkey.github.io/) 或 Tampermonkey
2. 一键安装脚本（Greasy Fork）：
   - **B 站版** → https://greasyfork.org/zh-CN/scripts/592929
   - **YouTube 版** → https://greasyfork.org/zh-CN/scripts/592932
3. 打开对应网站首页，点击左下角开关条上的 **⚙**，填入你自己的 DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) 申请，费用自理；两个站点需各设置一次）
4. 不填 Key 也能用：退回本地关键词规则分类（免费，但准确率明显更低）

## 隐私说明

- 启用 LLM 分类后，**仅视频的「标题、UP主名、标签」** 会发送给你选择的 API 服务商（默认 DeepSeek）用于分类
- **不会**发送你的账号信息、Cookie、观看历史或任何身份数据
- API Key 仅保存在你自己浏览器的 localStorage 中，不写在代码里、不上传到任何地方
- 分类结果缓存在本地，无任何遥测或数据收集

## 对平台的态度

本项目的设计原则是**不损害平台与创作者的任何权益**：

- **不屏蔽任何广告**：B 站的商业推广卡/课堂推广位、YouTube 的信息流广告在所有模式下原样展示
- **不劫持流量**：所有卡片均直接链接到平台原始视频页，不做嵌入、不做转链
- **不减少创作者收益**：观看行为完全发生在平台站内
- **克制的请求量**：B站版后台预取有全局节流、指数退避与后台降频，请求量与正常浏览同数量级；YouTube 版零额外站内请求，且在分类积压时主动暂停平台自身的加载
