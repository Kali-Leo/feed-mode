# B站首页 娱乐/专业 模式切换

一个 B 站首页用户脚本：用 LLM 把推荐流按内容价值分类，一键在四种模式间切换——

- **全部**：原生首页，不做任何改动
- **娱乐**：全部娱乐内容
- **精选娱乐**：只看能带来优质情绪价值的娱乐（治愈、欢笑、才华、匠心、萌宠、美好），过滤引战对立、猎奇审丑、贩卖焦虑的内容
- **专业**：只看有信息密度的内容（硬核科普、技术、财经分析、学术、深度纪录片）

另有「破茧」滑条（专业模式下）：按你设定的比例混入来自知识/科技分区和全站热门的圈外精选，作为打破信息茧房的手段。

## 特性

- **LLM 分类**：视频按「标题 + UP主 + 标签」由大模型分四类（专业/精选娱乐/普通娱乐/营销水），营销号、卖课引流、标题党在过滤模式下自动隐藏
- **缓冲池预取**：后台调用 B 站推荐接口提前分类，过滤模式下无饥饿感；池子持久化，刷新页面秒恢复
- **零位移信息流**：过滤模式下已显示的卡片永不前后移动
- **手动纠正**：卡片角标点击循环纠正分类（专→优→娱），Shift+点击记住某 UP 主的分类
- **分类缓存**：同一视频只分类一次，成本极低（重度使用每月约几元人民币的 API 费用）
- **限流保护**：所有后台请求全局节流、随机间隔、指数退避，后台标签页自动降频

## 安装

1. 安装用户脚本管理器：[Violentmonkey](https://violentmonkey.github.io/) 或 Tampermonkey
2. 安装本脚本（`bilibili-feed-mode.user.js`）
3. 打开 [bilibili.com](https://www.bilibili.com)，点击左下角开关条上的 **⚙**，填入你自己的 DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) 申请，费用自理）
4. 不填 Key 也能用：退回本地关键词规则分类（免费，但准确率明显更低）

## 隐私说明

- 启用 LLM 分类后，**仅视频的「标题、UP主名、标签」** 会发送给你选择的 API 服务商（默认 DeepSeek）用于分类
- **不会**发送你的账号信息、Cookie、观看历史或任何身份数据
- API Key 仅保存在你自己浏览器的 localStorage 中，不写在代码里、不上传到任何地方
- 分类结果缓存在本地，无任何遥测或数据收集

## 对哔哩哔哩的态度

本脚本的设计原则是**不损害平台与创作者的任何权益**：

- **不屏蔽任何广告**：B 站的商业推广卡、课堂等自营推广位在所有模式下原样展示
- **不劫持流量**：所有卡片均直接链接到 B 站原始视频页，不做嵌入、不做转链
- **不减少创作者收益**：观看行为完全发生在 B 站站内
- **克制的请求量**：后台预取有全局节流、指数退避与后台降频，请求量与正常浏览同数量级
